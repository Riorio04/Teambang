Step 5
Every path to the title
Game 2 of B vs C comes first. Everything branches from it.
B wins Game 2: B has 6 points. C can reach 3 at most. B is champion.
C wins Game 2: the series goes to Game 3.
B wins Game 3: B has 5, C can reach only 4. B is still champion.
C wins Game 3: B stops at 4, C has 2. Now A vs C decides it.
C needs a 2–0 over A to win outright. 2–1 ties B. If A wins, B is champion.
